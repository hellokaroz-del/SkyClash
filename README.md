# SkyClash (Ages of Aether)

เกมยิงปืนใหญ่ผลัดตาบนเบราว์เซอร์ เล่นกับบอท เล่นสองคนเครื่องเดียว หรือเล่นออนไลน์กับเพื่อน

## เล่นออนไลน์
1. คนหนึ่งกด **ออนไลน์** แล้วกด **สร้างห้อง** จะได้รหัส 4 หลัก
2. ส่งรหัสให้เพื่อน เพื่อนกด **ออนไลน์** ใส่รหัส แล้วกด **เข้าห้อง**
3. ต่างคนเลือกอาชีพของตัวเอง เจ้าของห้องเลือกด่านแล้วกด **เริ่มต่อสู้**

สองเครื่องต่อกันตรงผ่าน WebRTC ([PeerJS](https://peerjs.com), MIT) เครื่องเจ้าของห้องเป็นตัวคำนวณเกม ถ้าเจ้าของห้องสลับไปแท็บอื่น เกมจะหยุดรอ

## ไฟล์
- `index.html` ตัวเกมทั้งหมด
- `assets/` รูปและเสียง
- `game-data.json` อาชีพ สกิล ด่าน ที่บันทึกจากตัวสร้างเกม
- `sounds/` เพลงประจำด่าน
- `peerjs.min.js` ตัวเชื่อมต่อสองเครื่อง (PeerJS 1.5.4)
