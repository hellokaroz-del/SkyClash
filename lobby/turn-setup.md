# ตั้งเซิร์ฟเวอร์กลาง (TURN) ให้จับคู่ออนไลน์ต่อติดทุกเน็ต

ทำครั้งเดียว ประมาณ 10 นาที ฟรี (Cloudflare ให้ใช้ฟรี 1,000 GB ต่อเดือน)

**ทำไมต้องมี:** ตอนจับคู่ เกมให้สองเครื่องส่งข้อมูลหากันตรงๆ แต่เน็ตบ้านหลายเจ้าบล็อกการต่อตรง
(สองคนอยู่คนละบ้าน จับคู่ได้แต่ค้างหน้า "กำลังรอคู่แข่งเข้าเกม...")
เซิร์ฟเวอร์กลางจะส่งข้อมูลต่อให้แทน ผู้เล่นไม่ต้องทำอะไรเพิ่ม กดลุยแล้วเจอกันเหมือนเดิม

## 1. สร้าง TURN ใน Cloudflare
1. เข้า https://dash.cloudflare.com แล้วสมัครหรือล็อกอิน (ไม่ต้องมีโดเมน ไม่ต้องใส่บัตร)
2. เมนูซ้ายหา **Realtime** (ถ้าไม่เจอ พิมพ์ `TURN` ในช่องค้นหาด้านบน) > **TURN Server**
3. กด **Create** ตั้งชื่อ `ages-of-aether` > Create
4. จะได้ 2 ค่า **ก๊อปเก็บไว้เลย** (API Token โชว์ครั้งเดียว)
   - **Turn Token ID** (บางหน้าเรียก Key ID)
   - **API Token**

## 2. ใส่ฟังก์ชันใน Supabase
1. Supabase > โปรเจกต์ของเกม > เมนูซ้าย **Edge Functions**
2. กด **Deploy a new function** > **Via Editor**
3. ตั้งชื่อฟังก์ชันว่า `turn-credentials` (ต้องตรงตัวนี้เป๊ะ)
4. ลบโค้ดตัวอย่างในช่องแก้ไขออกให้หมด แล้ววางโค้ดทั้งไฟล์จาก
   `supabase/functions/turn-credentials/index.ts` ใน repo นี้
5. กด **Deploy function**
6. เปิดฟังก์ชันที่เพิ่งสร้าง > **Details** (หรือ Settings) ตรวจว่า **Verify JWT** เปิดอยู่ (ค่าเริ่มต้นเปิดอยู่แล้ว)
   ข้อนี้ทำให้เฉพาะผู้เล่นที่ล็อกอินแล้วเท่านั้นที่ขอใช้เซิร์ฟเวอร์กลางได้

## 3. ใส่ค่าจาก Cloudflare เป็นความลับ
1. Supabase > **Edge Functions** > **Secrets** (บางหน้าอยู่ใน Project Settings > Edge Functions)
2. กด **Add new secret** สองตัว
   - Name `CF_TURN_KEY_ID` ค่า = Turn Token ID จากข้อ 1
   - Name `CF_TURN_API_TOKEN` ค่า = API Token จากข้อ 1
3. กด **Save**

ค่าพวกนี้อยู่ในเซิร์ฟเวอร์ Supabase เท่านั้น ไม่หลุดไปในหน้าเว็บ หน้าเว็บได้แค่รหัสชั่วคราวที่หมดอายุใน 1 วัน

## 4. ลองเล่น
1. รีเฟรชหน้าเมืองทั้งสองเครื่อง (Ctrl+Shift+R) มุมล่างต้องขึ้นเวอร์ชันใหม่
2. ต่างคนต่างอยู่บ้านตัวเอง กดลุยพร้อมกัน ควรเข้าเกมได้

ถ้ายังไม่ได้:
- Supabase > Edge Functions > `turn-credentials` > **Logs** ดูว่ามีคำว่า `not_configured` (ยังไม่ได้ใส่ Secrets ข้อ 3)
  หรือ `cloudflare_401` (ก๊อป API Token ผิด สร้างใหม่ในข้อ 1 แล้วใส่ใหม่)
- ถ้าไม่ได้ตั้งค่านี้ เกมยังเล่นได้ตามปกติ แค่คู่ที่เน็ตบล็อกการต่อตรงจะต่อไม่ติดเหมือนเดิม
